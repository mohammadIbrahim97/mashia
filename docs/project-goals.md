# Mashia — Project Goals

**Project:** Mashia — Sheep Marketplace Platform (Syria → GCC)
**Date:** 2026-04-06
**Author:** Mohammad Ibrahim (Founder & Lead Dev)

---

## Ultimate Goal

**Ship the Sheep Marketplace MVP to production on AWS Bahrain and publish on App Store + Google Play.**

---

## 3 Main Goals

### Goal 1: Build a Production-Ready Backend API

Deliver a fully tested, containerized NestJS backend with all 8 modules (auth, users, listings, orders, payments, certificates, messaging, admin) deployed on AWS ECS Bahrain.

**Done when:** API is live, all endpoints return correct responses, database is seeded, CI/CD pipeline deploys automatically.

---

### Goal 2: Ship a Polished Mobile App to App Store & Google Play

Deliver a React Native app with full buyer/seller flows — registration, browsing, messaging, ordering, payments — with RTL Arabic support and trilingual UI.

**Done when:** App passes Apple/Google review, installs and runs on real devices, all core flows work end-to-end against the live API.

---

### Goal 3: Launch the Admin Dashboard for Platform Operations

Deliver a Next.js web dashboard where admins can verify KYC, moderate listings, manage disputes, track payments, and monitor platform KPIs.

**Done when:** Dashboard is deployed, an admin can manage the full platform lifecycle without touching the database directly.
